Delivery

The agent writes "..." where a person would pause. Slightly under 1.0 rate reads as considered rather than rushed. The voice selected here is the agent's own — spoken replies follow the language actually being used on the call.

Turn detection

The live threshold tracks the room and sits this many times above it, so the RMS box is a floor rather than the whole rule. Raise the noise margin when background voices are getting answered; raise barge-in seconds when the agent is cut off by coughs or line echo.

Silence handling

When nothing comes back for the check interval the agent asks whether it can be heard — and if audio was heard but discarded, it asks the caller to speak louder instead. Set the interval to 0 to never ask.
